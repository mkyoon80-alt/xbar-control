# XBAR Control

**XBAR 주파수 오프셋만** 조정하는 Windows 전용 앱입니다. RTX 5090에서 읽기를 확인했으며, RTX 50 시리즈 전체의 호환성은 검증하지 않았습니다.

## 라이트 / 다크 모드 (1.1)

창 오른쪽 위에서 **라이트** 또는 **다크**를 선택하면 바로 전환됩니다. 선택은 자동으로 저장되어 다음 실행과 관리자 재실행에도 유지됩니다. 테마 전환은 입력 중인 오프셋이나 GPU 설정을 변경하지 않습니다.

테마 설정은 `%LOCALAPPDATA%\XbarControl\theme.txt`에 저장됩니다. 저장된 설정이 없으면 라이트 모드로 시작합니다.

## 실행과 사용

1. `XbarControl.exe`를 더블클릭합니다. Python, 브라우저, 원본 BYSS_GPUOC는 필요하지 않습니다.
2. 현재 적용값과 실측 XBAR 클럭을 확인합니다.
3. 값을 적용하려면 **관리자 권한으로 열기**를 누르고 Windows 권한 창을 직접 승인합니다. 새로 열린 앱은 GPU의 현재 값부터 다시 읽습니다.
4. 슬라이더, 직접 입력, 또는 ±15 MHz 버튼으로 조정할 값을 준비합니다.
5. **XBAR 적용**을 누르면 XBAR 오프셋을 변경하고, 드라이버에서 다시 읽어 요청값과 비교합니다.

**코어·메모리·전압 조절 기능은 없습니다.** 숫자 입력과 슬라이더 조작은 입력값만 바꿉니다. **리셋**은 0 MHz를 준비하며, **XBAR 적용**을 눌러야 반영됩니다. 앱 종료 시 자동 복원은 하지 않습니다. 시작 시 적용은 아래 옵션을 켠 경우에만 동작합니다.

관리자 권한이 없거나 드라이버 검사에 실패한 경우 적용 버튼이 비활성화됩니다. `F5` 또는 새로고침으로 다시 읽을 수 있습니다. GPU가 여러 개면 장치를 선택할 수 있습니다.

화면 상단에서 GPU 연결 상태와 관리자 권한을 확인하고, 왼쪽에서 값을 조정하며, 오른쪽에서 자동 적용을 설정합니다. **리셋 / XBAR 적용**과 자동 적용 진행 메시지·취소 버튼은 하단에 고정됩니다. **저장 정보 · 연결 상세 · 최근 기록**을 펼치면 추가 정보를 볼 수 있습니다.

입력 한계는 −1000~+1000 MHz이며, 슬라이더는 처음에 −300~+500 MHz를 보여 줍니다. 이 범위는 입력 한계이며 안정성이 검증된 권장값을 뜻하지 않습니다. 실측 클럭은 부하와 전력 상태에 따라 달라지므로 오프셋 값과 다릅니다.

## 시작 시 자동 적용 (1.3)

두 옵션은 기본으로 꺼져 있으며, 각각 켜거나 둘 다 켤 수 있습니다.

1. 먼저 원하는 값을 직접 적용하고 현재 적용값을 확인합니다.
2. 오른쪽 **자동 적용값 저장**을 누릅니다. GPU에서 새로 읽은 현재 적용값을 저장합니다. 입력 중인 숫자는 저장하지 않습니다.
3. **앱 실행 시 적용**: 앱을 열 때 저장한 값을 적용합니다. 관리자 권한이 없으면 Windows 승인 창이 표시됩니다. 승인을 취소하면 적용하지 않습니다.
4. **Windows 시작 시 적용**: 관리자 권한으로 앱을 연 뒤 선택합니다. 현재 사용자의 Windows 로그인 30초 후 앱을 실행하여 저장한 값을 적용합니다. 적용에 성공하면 창을 최소화합니다.

자동 적용 전에 5초 카운트다운이 표시됩니다. **이번 자동 적용 취소**, 값 편집, GPU 변경, 창 닫기로 해당 실행의 적용을 취소할 수 있습니다. 취소해도 다음 실행 옵션은 유지됩니다. 옵션을 끄면 이후 자동 적용을 중지합니다. Windows 시작 옵션을 끄면 해당 예약 작업을 삭제합니다.

**저장된 값은 직접 적용하거나 리셋해도 자동으로 덮어쓰지 않습니다.** 새 값을 시작 시에도 쓰려면 **자동 적용값 저장**을 다시 누르세요. 기본값으로 계속 사용하려면 리셋 → XBAR 적용 → 자동 적용값 저장 순서로 진행하거나 시작 옵션을 끄세요.

저장 버튼 아래에는 저장할 현재 적용값이 표시되고, 저장이 끝나면 오른쪽 하단에 **저장 완료**가 표시됩니다. 저장은 GPU 값을 바꾸지 않으므로 현재 적용값과 입력 숫자는 그대로입니다.

### 1.2에서 업데이트하는 경우

기존 Windows 자동 실행 작업은 이전 EXE와 20초 대기 시간을 유지합니다. 새 EXE를 관리자 권한으로 열고 **Windows 시작 시 적용**을 껐다 켜면 저장값을 유지하면서 새 EXE와 30초 대기 시간으로 갱신됩니다. 새 현재 적용값까지 저장하려면 **자동 적용값 저장**을 사용해도 됩니다. 로그인 30초 후 앱을 실행하고, 실행 후 5초 취소 시간을 거쳐 적용합니다.

저장한 GPU 이름·PCI 버스, 드라이버 버전과 라이브러리 해시가 현재 환경과 일치해야 자동 적용합니다. GPU/드라이버가 바뀌면 현재 값을 확인하고 다시 저장하세요. 자동 적용 실패나 미완료 기록이 있으면 두 옵션을 끕니다. 실패 후 자동 재시도는 하지 않습니다. 이 기록은 읽기 검증까지의 실패를 감지하며, 이후의 오버클럭 안정성을 판정하는 기능은 아닙니다.

Shift를 누른 채 앱을 시작하거나 `XbarControl.exe --skip-auto`로 실행하면 그 실행의 자동 적용을 건너뜁니다. Windows 시작 동작까지 중지하려면 앱에서 해당 옵션을 끄세요.

### 저장 및 설치 위치

- 자동 적용 설정: `%LOCALAPPDATA%\XbarControl\startup.json`
- 미완료 감지 기록: 같은 폴더의 `auto-apply.pending`
- Windows 시작 옵션을 켜면 보호된 `%ProgramFiles%\XbarControl\<사용자 SID>\`에 실행 파일 복사본을 설치합니다. 일반 사용자에게는 읽기·실행 권한만 부여합니다.
- 작업 스케줄러의 `XBAR Control - <사용자 SID>` 작업으로 해당 사용자 로그인 시 실행합니다. 암호를 저장하거나 SYSTEM 계정을 사용하지 않습니다.
- Windows 시작 옵션을 끄면 예약 작업이 제거됩니다. 설치 복사본은 남으며, 완전히 제거하려면 옵션을 끈 뒤 앱을 종료하고 해당 설치 폴더를 삭제할 수 있습니다.
- 새 버전으로 자동 실행 파일을 갱신하려면 새 EXE를 관리자 권한으로 열고 **자동 적용값 저장**을 누르세요. Windows 시작 옵션이 켜져 있으면 실행 복사본과 등록도 갱신합니다.

## 이번 빌드에서 확인한 내용

- RTX 5090 / NVIDIA 616.92에서 실제 값 읽기 및 화면 연결 확인.
- 설치된 NVIDIA 제어 라이브러리의 GET/SET 구조와 XBAR 필드 위치를 정적으로 분석. 해당 라이브러리 SHA-256을 고정해 616.92 지원 범위를 한정.
- XBAR 이외 도메인을 선택하지 않도록 쓰기 마스크를 `0x2`로 제한. 전압과 다른 필드의 기존 바이트를 유지.
- 제어 데이터·설정 테스트 29개, 화면 입력·갱신 충돌·자동 적용 취소·작은 창 입력 영역 검사 20개 통과. 화면 테스트는 라이트·다크에서 확인.
- Windows 작업 스케줄러에서 등록 형식과 등록 상태 조회를 검증. 실제 예약 작업 등록 및 Windows 재로그인 시험은 수행하지 않음.
- **실제 GPU에 값을 쓰는 테스트와 오버클럭 안정성 테스트는 하지 않았습니다. 개발 중 GPU 설정 변경은 없습니다.**

616.92의 다른 라이브러리 파일이나 검증 목록 밖 드라이버는 읽기 전용으로 동작할 수 있습니다. 드라이버 버전 문자열만 바꾸어 검사를 통과시키지 않습니다.

Windows 10/11 64비트, .NET Framework 4.8 환경을 대상으로 합니다. 개발 환경의 기본 Windows 런타임으로 빌드하고 실행을 확인했습니다.
