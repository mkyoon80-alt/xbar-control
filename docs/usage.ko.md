# XBAR Control

**XBAR 주파수 오프셋만** 조정하는 Windows 전용 앱입니다. RTX 5090에서 읽기를 확인했으며, RTX 50 시리즈 전체의 호환성은 검증하지 않았습니다.

## 라이트 / 다크 모드 (1.1)

창 오른쪽 위에서 **라이트** 또는 **다크**를 선택하면 바로 전환됩니다. 선택은 자동으로 저장되어 다음 실행과 관리자 재실행에도 유지됩니다. 테마 전환은 입력 중인 오프셋이나 GPU 설정을 변경하지 않습니다.

테마 설정은 `%LOCALAPPDATA%\XbarControl\theme.txt`에 저장됩니다. 저장된 설정이 없으면 라이트 모드로 시작합니다.

## 실행과 사용

1. `XbarControl.exe`를 더블클릭합니다. Python, 브라우저, 원본 BYSS_GPUOC는 필요하지 않습니다.
2. 현재 적용값과 실측 XBAR 클럭을 확인합니다.
3. 값을 적용하려면 **관리자 권한으로 열기**를 누르고 Windows 권한 창을 직접 승인합니다. 새로 열린 앱은 GPU의 현재 값부터 다시 읽습니다.
4. 슬라이더, 직접 입력, 또는 ±15 MHz 버튼으로 조정할 값을 준비합니다.
5. **XBAR 적용**을 누르면 XBAR 오프셋을 변경하고, 드라이버에서 다시 읽어 요청값과 비교합니다.

**코어·메모리·전압 조절 기능은 없습니다.** 시작할 때, 숫자를 입력할 때, 슬라이더를 움직일 때는 GPU 설정을 바꾸지 않습니다. ‘0 MHz로 준비’와 ‘시작 값으로 준비’도 입력값만 바꾸며 별도로 적용해야 합니다. 앱 종료 시 자동 복원이나 재부팅 후 자동 적용 기능은 없습니다.

관리자 권한이 없거나 드라이버 검사에 실패한 경우 적용 버튼이 비활성화됩니다. `F5` 또는 새로고침으로 다시 읽을 수 있습니다. GPU가 여러 개면 장치를 선택할 수 있습니다.

입력 한계는 −1000~+1000 MHz이며, 슬라이더는 처음에 −300~+500 MHz를 보여 줍니다. 이 범위는 입력 한계이며 안정성이 검증된 권장값을 뜻하지 않습니다. 실측 클럭은 부하와 전력 상태에 따라 달라지므로 오프셋 값과 다릅니다.

## 이번 빌드에서 확인한 내용

- RTX 5090 / NVIDIA 616.92에서 실제 값 읽기 및 화면 연결 확인.
- 설치된 NVIDIA 제어 라이브러리의 GET/SET 구조와 XBAR 필드 위치를 정적으로 분석. 해당 라이브러리 SHA-256을 고정해 616.92 지원 범위를 한정.
- XBAR 이외 도메인을 선택하지 않도록 쓰기 마스크를 `0x2`로 제한. 전압과 다른 필드의 기존 바이트를 유지.
- 제어 데이터 테스트 13개, 화면 입력 및 자동 갱신 충돌 테스트 13개 통과.
- **실제 GPU에 값을 쓰는 테스트와 오버클럭 안정성 테스트는 하지 않았습니다. 개발 중 GPU 설정 변경은 없습니다.**

616.92의 다른 라이브러리 파일이나 검증 목록 밖 드라이버는 읽기 전용으로 동작할 수 있습니다. 드라이버 버전 문자열만 바꾸어 검사를 통과시키지 않습니다.

Windows 10/11 64비트, .NET Framework 4.8 환경을 대상으로 합니다. 개발 환경의 기본 Windows 런타임으로 빌드하고 실행을 확인했습니다.
